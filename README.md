# AdventureWorks-Sales-Performance-Dashboard
Executive Sales Performance Dashboard built in Power BI using AdventureWorks data. The dashboard leverages DAX measures, fiscal-year KPI comparisons, interactive slicers, bookmark-driven reset functionality, and advanced visualizations to monitor revenue, profitability, product performance, and regional sales trends.

# Project Overview
This project is an interactive Power BI dashboard built using the AdventureWorks Sales dataset. The dashboard analyzes revenue, profit, orders, units sold, average order value, regional performance, category performance, and top/bottom product performance.

# Business Objective
The goal of this dashboard is to help business stakeholders understand overall sales performance and identify key drivers of revenue and profitability.

# Key Business Questions
- What is the total revenue, profit, and profit margin?
- How are sales performing over time?
- Which regions generate the highest revenue?
- Which product categories contribute most to revenue?
- What are the top and bottom products by revenue?
- How do current KPIs compare with the previous fiscal year?

# Tools Used
- Power BI
- Power Query
- DAX
- Excel

# Dashboard Features
- KPI cards with YoY comparison
- Revenue trend over time
- Revenue by region
- Revenue by category
- Top 5 products by revenue
- Bottom 5 products by revenue
- Fiscal Year, Region, and Category slicers
- Reset filter button using bookmarks
- Conditional formatting for negative profit

# Key KPIs
- Total Revenue
- Total Profit
- Profit Margin
- Total Orders
- Units Sold
- Average Order Value

# Insights
- Total revenue was $109.81M.
- Total profit was $12.55M.
- Profit margin was 11.43%.
- Revenue increased by 52.3% YoY.
- Road-650 generated high revenue but negative profit, indicating a profitability issue.
- Bikes contributed the highest revenue by category.
